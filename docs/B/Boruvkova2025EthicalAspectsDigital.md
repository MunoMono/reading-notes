# Definitions / terms this changes (only the ones that matter)

- **Digital reconstruction:** interpretative supplementation of damaged or incomplete cultural heritage using surviving evidence, historical references and expert judgement; its reconstructed components require explicit documentation. `[@Boruvkova2025EthicalAspectsDigital, pp. 217–219]`
- **Authenticity:** not simply visual plausibility, but a relationship between surviving evidence, historical context, documented intervention and interpretative integrity.
- **Layered authenticity:** recognition that a heritage object can embody multiple historical states and interventions that should remain identifiable rather than being collapsed into a single idealised representation. `[@Boruvkova2025EthicalAspectsDigital, p. 224]`
- **Scoped missingness:** my archival extension of this principle: the system identifies where the available evidence ceases to support reconstruction or inference and retains that limit as part of the historical representation.
