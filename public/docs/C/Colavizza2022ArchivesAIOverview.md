# Thesis job
Colavizza et al. locate AI across the records continuum, making provenance and archival context active requirements for computational work on DDR.

# Position + moment
The survey appears as AI moves from isolated archival experiments into wider recordkeeping workflows. [@Colavizza2022ArchivesAIOverview, pp. 1–5]

# The author’s main move
The authors map AI uses while arguing that provenance, context, appraisal and accountability should inform computational systems. [@Colavizza2022ArchivesAIOverview, pp. 1–14]

# Definitions / terms this changes
- **Archives as data:** computationally tractable archival holdings that retain evidential relationships. [@Colavizza2022ArchivesAIOverview, pp. 5–6]

- **Records Continuum:** the model connecting creation, capture, organisation and pluralisation. [@Colavizza2022ArchivesAIOverview, pp. 2–4]
